# War of the Gods — ElevenLabs Music v2 Prompts

Prompts para generar música de ambiente mexica/mesoamericana.
Usar en: https://elevenlabs.io/app/music (requiere plan de pago para uso comercial)

**Instrumento base para todos los prompts:**
- teponaztli (log drum de doble tono)
- huehuetl (tambor vertical de piel)
- chicahuaztli (sonajero/rattle)
- ocarina de barro / flauta de carrizo
- caracol / concha marina (quiquiztli)
- Sin instrumentos occidentales

---

## 1. TITLE — "Templo al Amanecer"
*Estado: pantalla de título. Mood: solemne, ancestral, eterno.*
*BPM referencia: 58 (muy lento)*

```
Slow ceremonial Mesoamerican ambient music, 58 BPM. Opening conch shell horn call fading into silence. Deep huehuetl drum with sparse single strikes. Teponaztli log drum entering gently, two-tone alternating pattern. Clay ocarina playing a descending pentatonic melody in D minor, long sustained notes with breath between each. Chicahuaztli rattle as subtle texture. Reverb-heavy, spacious, sacred atmosphere. No Western instruments. Loopable.
```

**Variante más oscura:**
```
Ancient Aztec temple ambient, dawn ritual. Single conch shell call. Sparse huehuetl heartbeat drum at 58 BPM. Teponaztli wood drum with hollow two-tone pattern. Descending clay flute melody, sorrowful and ancient. Deep cave reverb. Silence as a musical element. No melody rush — breath and space. Loopable instrumental.
```

## Notas de uso

- Generar 2–3 versiones de cada prompt, elegir la mejor
- Duración ideal: 60–90 segundos (el juego loopea la música)
- Exportar como MP3 o WAV
- Para integrar al juego: reemplazar `startMusic('title')` etc. con `new Audio('title-bg.mp3').play()`
- El código original está en `music-themes-backup.js` para restaurar si es necesario
